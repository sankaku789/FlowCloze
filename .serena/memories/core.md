FlowCloze is a Rust CLI/library that parses Markdown qblocks into Intermediate JSON and generates context-cloze documents for TUI/CSV/PDF. Public parser and Intermediate JSON compatibility are invariants. Stable generation architecture and Phase 1-5 contracts: `mem:generation_architecture`; provider boundaries/retry: `mem:provider_adapters`; located span/sentinel path: `mem:phase4_located_generation`; config precedence/secret indirection: `mem:generation_config`; final merge/fallback/sentinel invariants: `mem:generation_review_invariants`; public composer-error payload and private terminal-cause separation: `mem:generation_error_mapping`; redacted observability/FNV: `mem:observability`. Project onboarding references: `mem:tech_stack`, `mem:suggested_commands`, `mem:conventions`, `mem:task_completion`.
