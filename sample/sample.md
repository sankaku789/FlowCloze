
# 組込みシステムとは
#qblock{
- 各種機械・機器に組み込まれて，その制御を行う[専用化されたコンピュータシステム]のこと    
    + デスクトップアプリ/モバイルが人との窓口をするのに対して，組込みは物理世界との窓口となる
- 市場規模そのものが大きい(とはいえモバイルも相当大規模にある)
    + 家電やOA機器ｍ通信，工業制御，医療，宇宙，CSなど多岐にわたる
}

## 組込みシステムの構成要素

#qblock{
- センサ：[物理的な状態 -> 情報]
    + リミットスイッチ，フォトトランジスタ(光)，サーミスタ(温度)，マイク
- アクチュエータ：[情報 -> 物理的な状態]
    + モータ，LED，電熱線，スピーカー
- インターネット：情報を別コンピュータと送受信
    + **別に伝送先はインターネットとは限らない**
    + スマートリモコンなど
}


## 組込みシステムの特徴

#qblock{
- 構築の上では，次の特徴を取捨選択することが重要

---

- 専用化されたシステム
    + [ある1つの目的のために作られる]
    + 対義的に，汎用システムでは[特定の目的がなく，様々な用途に利用]される
    + 近年では汎用の機能も増加してる
        + ソフトの入れ替えは少なかったので最低限のHW/SWでよかった
        + 現在ではセキュリティなどSWの更新機会がそもそも増えている
- 厳しいリソース制約：
    + [コスト，サイズ・重量，電力，環境(動作温度等)]など多い．
    + クロック周波数と消費電力はトレードオフ
    + 例えば，5V動作から3.3V動作にすると，消費電力は低減できるがノイズによりセンサ等のやり取りが難しくなる．
- リアルタイム性の確保：
    + [システムが定められた時間制約で動作]するのがリアルタイム性(早すぎも遅すぎもだめ)
    + ハードリアルタイムシステム：[時間制約に違反するとシステムに致命的な影響]を与える
        + ex. エアバッグやエンジンの制御
    + ソフトリアルタイムシステム：[時間制約に違反しても致命的な影響はないが，システムの価値は低下]する
        + ex. ATMや自販機
- ディペンダビリティ：
    + 「広義の信頼性」([システムがどの程度頼りになるか])だが厳密に定義はできない
        + 安全性，信頼性，セキュリティ(機密，完全，可用)など
    + [信頼性(要求された機能の実行能力)が良いからと言って安全(システムが周囲に与える影響がない)]とは言えない．
        + 安全性を高める場合が多い．(要求仕様次第)
- 環境への対処：
    + 抵抗値は温度が上がると増える -> 半導体は温度が上がると発熱する．

---
}
