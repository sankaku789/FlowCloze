# FlowCloze intermediate JSON schema memo

## Goal

Gemini should generate context cloze questions, not one-question-one-answer cards.
The intermediate JSON should therefore describe a context-cloze generation task:

- keep one qblock as one question
- keep multiple blanks in one readable context
- fix blank positions and answer order before Gemini runs
- use `##` and `###` only as block separators, not as visible heading text
- reduce Gemini's responsibility to minimal wording cleanup and optional metadata

## Proposed shape

```json
{
  "schema_version": 2,
  "meta": {
    "source": "sample/sample.md",
    "format": {
      "blank": "＿＿＿",
      "block_separator": "\n",
      "paragraph_indent": "　"
    }
  },
  "tasks": [
    {
      "id": "qblock-001",
      "type": "context-cloze",
      "section": "ソフトウェア工学の概論",
      "source": {
        "raw": "qblock body before target markup is stripped",
        "plain": "qblock body after target markup is stripped"
      },
      "blocks": [
        {
          "id": "qblock-001-b001",
          "kind": "paragraph",
          "text": "- 情報システムは，人，機械，コンピュータが互いに協調してある目的を達成する仕組み全体のこと",
          "cloze_text": "　- ＿＿＿は，人，機械，コンピュータが互いに協調してある＿＿＿のこと",
          "target_refs": [0, 1]
        },
        {
          "id": "qblock-001-b002",
          "kind": "paragraph",
          "text": "- ソフトウェアはプログラム，データ，関連するドキュメント",
          "cloze_text": "　- ＿＿＿は＿＿＿，＿＿＿，関連する＿＿＿",
          "target_refs": [2, 3, 4, 5]
        }
      ],
      "cloze_template": "　- ＿＿＿は，人，機械，コンピュータが互いに協調してある＿＿＿のこと\n　- ＿＿＿は＿＿＿，＿＿＿，関連する＿＿＿",
      "targets": [
        {
          "index": 0,
          "answer": "情報システム",
          "type": "term-name",
          "block_id": "qblock-001-b001"
        },
        {
          "index": 1,
          "answer": "目的を達成する仕組み全体",
          "type": "meaning",
          "block_id": "qblock-001-b001"
        }
      ],
      "answers": [
        "情報システム",
        "目的を達成する仕組み全体",
        "ソフトウェア",
        "プログラム",
        "データ",
        "ドキュメント"
      ],
      "warnings": []
    }
  ]
}
```

## Field notes

`schema_version`

Version of the intermediate JSON protocol. Use `2` for the redesigned task-based schema.

`meta.format.blank`

The exact blank string to use in cloze text. Current value: `＿＿＿`.

`meta.format.block_separator`

Separator used when joining `blocks[].cloze_text` into `cloze_template`.
Markdown headings inside qblocks, such as `##` and `###`, should create block boundaries only.
Their heading text should not be included in `blocks` or in `cloze_template`.

`meta.format.paragraph_indent`

Prefix added to paragraph blocks. Current value: one full-width space, `　`.

`tasks`

Generation tasks. One task corresponds to one qblock and should produce one context-cloze question.

`tasks[].source.raw`

Original qblock body. Useful for debugging and regeneration.

`tasks[].source.plain`

Qblock body after `[answer]` / `[answer]{type}` markup is stripped.
This is for inspection and traceability, not the main generation input.

`tasks[].blocks`

Ordered text blocks used to build the cloze question.
For the current use case, `kind` can be `paragraph`.
Heading lines inside qblocks are delimiters only and should not become heading blocks.

`tasks[].blocks[].text`

Plain text for a block, with target markup stripped.

`tasks[].blocks[].cloze_text`

The same block after replacing target answers with `meta.format.blank`.
This should be generated by Rust, not Gemini.

`tasks[].blocks[].target_refs`

Indexes into `tasks[].targets` for targets that appear in this block.

`tasks[].cloze_template`

The complete context-cloze question template, produced by joining `blocks[].cloze_text`.
This is the main field Gemini should preserve.

`tasks[].targets`

Canonical ordered target list. The order defines blank order.

`tasks[].answers`

Canonical ordered answer list. This should be derived from `targets[].answer`.

## Responsibility split

Rust parser / intermediate JSON:

- extract qblocks
- extract targets
- strip target markup
- split qblock body into blocks
- treat `##` / `###` as block separators only
- generate `blocks[].cloze_text`
- generate `cloze_template`
- generate ordered `answers`

Gemini:

- produce one `context-cloze` result per task
- preserve `cloze_template` blank count and order
- avoid splitting a qblock into one-question-one-answer cards
- optionally make minimal wording cleanup if allowed
- produce `explanation`, `tags`, and `warnings` when useful

Validator:

- verify one output question per task id
- verify blank count equals `answers.len()`
- verify `answers` equals the task answer list in order
- verify output targets match input targets
- optionally verify `question` is exactly `cloze_template` if strict mode is desired
