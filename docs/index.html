Markdown to context cloze

FlowCloze

Markdownで書いた学習ノートから，文章補完問題のJSON，PDF，Ankilot向けCSVを生成するCLIツールです．

仕様を見る APIを見る

背景

Markdownノートは書きやすく見返しやすい一方で，用語や定義を正確に思い出す練習には少し弱いところがあります． 手作りの暗記シートは記憶に残りやすいものの，問題文作成，表計算ソフトへの転記，PDF整形に時間がかかります．

FlowClozeは，ノートの読みやすさを保ったまま，覚えたい語句だけを指定し，生成・検証・出力までを一連の流れにします．

流れ

Markdown

#qblock{ ... } で問題化する範囲を囲みます．

Targets

[答え] または [答え]{type} で解答対象を指定します．

Generate

Gemini APIで文章補完問題を生成します．

Validate

中間JSONと生成JSONを照合します．

Output

JSON，PDF，Ankilot向けCSVとして出力します．

主な機能

明示的な解答指定

Geminiには，Markdown内で指定したtargetsだけを答えにするよう指示します．

検証つき生成

空欄数，解答数，対象外の答え，IDの不整合を検出します．

複数形式の出力

TUI確認，Typst PDF，Ankilot CSVへつなげられます．
